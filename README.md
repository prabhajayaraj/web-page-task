# Host a Static Website with GitHub Pages

## Project Overview
This project demonstrates how to create and deploy a static website using GitHub Pages. The website is developed using HTML and CSS and hosted directly from a GitHub repository, making it publicly accessible through a live URL.

## Objectives
- Create a static website using HTML and CSS.
- Manage and version-control project files using Git.
- Push the source code to GitHub.
- Deploy the website using GitHub Pages.
- Access the published website through a public URL.

## Technologies Used
- HTML
- CSS
- Git
- GitHub
- GitHub Pages

## Project Setup and Deployment
1. Created the `index.html` file to define the website structure.
2. Added CSS styling to customize the website's appearance.
3. Initialized a Git repository and committed the project files.
4. Pushed the code to the GitHub repository.
5. Enabled GitHub Pages from the repository's Settings.
6. Selected the `main` branch and root folder for deployment.
7. Verified that the website was successfully published and accessible online.
